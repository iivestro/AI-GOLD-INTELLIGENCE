# AI GOLD INTELLIGENCE V5

## Project Vision
Global Economic Intelligence Engine.

## Main Objectives
- متابعة الذهب والأسواق العالمية.
- جمع الأخبار الاقتصادية من المصادر الرسمية.
- متابعة قرارات البنوك المركزية.
- جمع المؤشرات الاقتصادية التاريخية.
- تحليل العلاقات الاقتصادية.
- اكتشاف الأحداث غير المعتادة.
- إنشاء تقارير عربية تلقائية.
- حفظ تاريخ البيانات والتحليلات.

## Technical Architecture
- Frontend: HTML, CSS, JavaScript.
- Backend: Python.
- Automation: GitHub Actions.
- Storage: JSON.
- Hosting: GitHub Pages.

## Budget
Free services only.

## Data Integrity
- Display source and timestamp.
- Detect missing and stale data.
- Never label delayed data as live.
- Distinguish correlation from causation.

## Safety
Educational economic research only.
No trade execution or personalized trading signals.
